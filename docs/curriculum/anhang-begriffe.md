# Anhang – Begriffe / Glossary

Deutsch so, wie es in der Software steht (Spalte **Q** = Quelle: **S** = wörtlich in RatRocket
Code, `web/code-data.js` · **R** = Roboter-Befehl oder -Ausgabe · **K** = Kursbegriff dieses
Curriculums · **G** = geplant – Stand November 2026). English as in the software's English mode
where one exists.

## Bausteine und Bedingungen

| Deutsch | English | Q | Für Kinder erklärt |
|---|---|---|---|
| Baustein / Bausteine | block / blocks | S | Ein Befehl zum Ziehen; viele Bausteine untereinander sind ein Programm. |
| `fahre 1 Feld` | move 1 cell | S | Der Roboter fährt genau ein Feld geradeaus. |
| `drehe nach rechts` | turn right | S | Der Roboter dreht sich auf der Stelle eine Vierteldrehung nach rechts. |
| `drehe nach links` | turn left | S | Dasselbe nach links. |
| `dreh dich um` | turn around | S | Eine halbe Drehung: danach schaut der Roboter zurück. |
| `wiederhole … mal` | repeat … times | S | Alles im Bauch des Bausteins passiert so oft, wie die Zahl sagt (1 bis 9). |
| `wiederhole, bis du draußen bist` | repeat until you are out | S | Der Bauch läuft immer wieder, bis der Roboter das Labyrinth verlassen hat. |
| `wiederhole bis` … | repeat until … | S | Der Bauch läuft immer wieder, bis die Bedingung stimmt – geprüft vor jeder Runde. |
| `wenn` … `sonst` | if … else | S | Der Roboter fragt seine Augen (oder eine Variable) und macht dann das eine oder das andere. |
| `vorne frei` / `vorne Wand` | front is free / wall ahead | S | Ist vor dem Roboter in seinem Feld eine Wand oder nicht? |
| `rechts frei` / `rechts Wand` | right is free / wall right | S | Dasselbe auf seiner rechten Seite. |
| `links frei` / `links Wand` | left is free / wall left | S | Dasselbe auf seiner linken Seite. |
| Fahren · Wiederholen · Entscheiden · Variablen (Aufgabe 7: dazu Listen · Karte · Meine Bausteine) | Drive · Repeat · Decide · Variables (task 7: also Lists · Map · My blocks) | S | Die Farb-Gruppen der Bausteine. |
| Bauch | belly | S | Der Platz in einem Baustein, in den andere Bausteine kommen. |
| Variable | variable | S | Ein Zettel mit Namen, auf dem sich das Programm eine Zahl merkt. Bei jedem Start steht 0 darauf. |
| `setze` … `auf` … / `ändere` … `um` … | set … to … / change … by … | S | Schreibt eine Zahl auf den Zettel / zählt etwas dazu (mit −1 weg). |
| `zeige` … | show … | S | Der Roboter zeigt in einer Sprechblase, was auf dem Zettel steht. |
| `=` `>` `<` | = > < | S | gleich, größer als, kleiner als – so vergleicht man eine Variable mit einer Zahl. |
| Liste (`füge … zu … hinzu`, `Element … von …`, `Länge von …`) | list (add … to …, item … of …, length of …) | S | Viele Zettel in einer Reihe – zum Beispiel alle Richtungen, die der Roboter gefahren ist. Element 1 ist das erste. |
| eigener Baustein (Meine Bausteine, `definiere …`) | own block (My blocks, define …) | S | Ein selbst gebauter Baustein, der aus anderen Bausteinen besteht – in echten Sprachen eine *Funktion*. |
| Karten-Bausteine (`merke Wände hier`, Zahl von Feld, `offen laut Karte`) | map blocks (remember walls here, number of cell, open on map) | S | Das Gedächtnis des Roboters als Bausteine: Wände merken, Zahlen in Felder schreiben – damit baust du die Zahlenflut selbst. |
| Profi-Wörter | Pro words | S | Knopf oben: Die Bausteine zeigen die Wörter echter Programmiersprachen (`if`, `else`, `repeat`, `set` …). |
| parametrischer Baustein (`fahre … cm`, `drehe … Grad`) | parametric block | G | Ein Baustein mit Zahl, z. B. „fahre 30 cm" statt „fahre 1 Feld". |

## Labyrinth und Roboter

| Deutsch | English | Q | Für Kinder erklärt |
|---|---|---|---|
| Labyrinth | maze | S | Ein Raster aus Feldern mit Wänden dazwischen. |
| Feld | cell | S | Ein Quadrat im Labyrinth, 16 cm groß. |
| Wand | wall | S | Etwas zwischen zwei Feldern, durch das der Roboter nicht fahren kann. |
| Ausgang, Öffnung | exit, opening | S | Eine Lücke in der Außenwand; wer hindurchfährt, ist draußen. |
| Start, Startfeld | start, start cell | S | Wo der Roboter steht, bevor es losgeht – meist unten links, Blick nach oben. |
| Sackgasse | dead end | K | Ein Feld mit drei Wänden: Hier geht es nur zurück. |
| Insel | island | K | Ein Wandstück ohne Verbindung zur Außenwand; die rechte Hand kommt nie daran vorbei. |
| Sensor, Abstandssensor, Ultraschall | sensor, distance sensor, ultrasound | S | Misst, wie weit die nächste Wand weg ist – mit einem Echo, wie eine Fledermaus. |
| Schwelle | threshold | K | Ab diesem Abstand sagt der Roboter „Wand", darüber „frei". |
| Zähler an den Rädern (Encoder), Puls | wheel encoder, pulse | S | Zählt winzige Schritte der Raddrehung; daraus weiß der Roboter, wie weit er gefahren ist. |
| Umdrehung, Radumfang | revolution, circumference | K | Einmal ganz herum; dabei rollt das Rad seinen Umfang ab (π · Durchmesser). |
| PWM, Tastgrad, high/low | PWM, duty cycle, high/low | R | Den Motor ganz schnell ein- (*high*) und ausschalten; je länger „ein", desto kräftiger. |
| Regler, PID (P, I, D) | controller, PID | R | Misst immer wieder, wie weit Ist und Soll auseinander sind, und korrigiert. |
| Spurbreite | track width | R | Abstand zwischen den beiden Rädern (96 mm); wichtig fürs genaue Drehen. |
| Kalibrieren | calibrate | K | Mit einem Lineal nachmessen und dem Roboter seine echten Maße beibringen. |
| Gyroskop | gyroscope | G | Ein Sensor, der spürt, wie schnell sich der Roboter dreht. |
| DIP-Schalter, Modus | DIP switch, mode | R | Kleine Schalter auf der Platine; sie wählen beim Start, welches Programm läuft. |
| Labyrinth-Modus | maze mode | R | SW3 an, SW1 und SW2 aus – der Modus für RatRocket Code. |
| Bluetooth-Modul | Bluetooth module | R | Steckteil für die Funkverbindung zum Laptop („ohne Leine"). |
| Befehl (`CELL`, `TURN`, `WALLS`, `FWD`, `GO` …) | command | R | Eine Textzeile, die der Roboter versteht; jeder Baustein schickt so einen Befehl. |
| Testseite | test page (`web/maze_event.html`) | K | Englische Werkstatt-Seite mit Befehlsfeld und Roboter-Protokoll. |
| Firmware | firmware | R | Das Programm, das fest im Roboter läuft. |
| RATROCKET-Laufwerk, UF2 | update drive, UF2 file | R | Im Update-Modus erscheint der Roboter als USB-Stick; eine Datei darauf kopieren = neue Firmware. |
| Erklär-Seiten | explainer pages (`web/learn.html`) | K | Bewegte Erklärungen zu PID, Pulsen, PWM, Ultraschall, Flood-Fill (im Aufbau – Stand November 2026). |

## Algorithmen und Ideen

| Deutsch | English | Q | Für Kinder erklärt |
|---|---|---|---|
| Programm | program | S | Eine Liste von Befehlen, die der Reihe nach ausgeführt wird. |
| Reihenfolge (Sequenz) | sequence | K | Was zuerst kommt, passiert zuerst. |
| Schleife | loop | K | Etwas wird wiederholt. |
| Bedingung, Verzweigung | condition, branch | K | Eine Ja/Nein-Frage, nach der sich das Programm teilt. |
| Algorithmus | algorithm | K | Ein genaues Rezept, das ein Problem immer löst. |
| Debuggen | debugging | K | Fehler im Programm suchen und beheben. |
| Rechte-Hand-Regel, Wandfolger | right-hand rule, wall follower | K | Immer die rechte Hand an der Wand lassen – so findet man aus jedem Labyrinth mit Ausgang am Rand. |
| Karte | map | R | Was der Roboter über die Wände weiß: Wand, frei oder noch nicht gesehen. |
| Gedächtnis, Speicher | memory | K | Was ein Roboter sich merken kann (Karte, besuchte Felder). |
| Brotkrumen, Stapel | breadcrumbs, stack | K | Markierungen für besuchte Felder und ein Kartenstapel für den Rückweg. |
| Tiefensuche | depth-first search | K | Erst so tief wie möglich hinein, dann zurück zur letzten Abzweigung. |
| Zahlenflut (Flood-Fill) | flood fill | K | Zahlen „fließen" vom Ziel durchs Labyrinth; jede Zahl sagt, wie viele Felder es bis zum Ziel sind. |
| Breitensuche, Warteschlange | breadth-first search, queue | K | Welle für Welle vom Ziel aus; wer zuerst in die Schlange kommt, ist zuerst dran. |
| kürzester Weg | shortest path | K | Der Weg mit den wenigsten Feldern – immer bergab bei der Zahlenflut. |
| Erkundungslauf / Schnelllauf | exploration run / speed run | K | Erst das Labyrinth kennenlernen, dann so schnell wie möglich ins Ziel. |
| Micromouse | Micromouse | K | Ein Wettbewerb, bei dem kleine Roboter allein den Weg in die Mitte eines Labyrinths finden. |
| Textprogrammierung | text programming | G | Programmieren mit getipptem Text statt mit Bausteinen. |
| Programm auf dem Roboter | program stored on the robot | G | Das Programm bleibt im Roboter und läuft ohne Laptop. |
| freies Baufenster | free-build window | G | Offene Programmierfläche mit eigener Simulationswelt. |
| Werkstatt | workshop (calibration) | G | Bereich in RatRocket Code zum Messen und Einstellen des Roboters. |
